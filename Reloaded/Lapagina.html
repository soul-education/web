Souleducation Reloaded

Bienvenidos a la versión renovada de souleducation.xs3.com, un proyecto que revive la esencia del sitio original de los 2000s pero con el poder de las tecnologías actuales: JavaScript y HTML moderno.

Este espacio fue creado como un desafío personal: comprobar qué podía lograr trabajando únicamente con Copilot y un editor de texto sencillo (Geany), delegando en la IA gran parte de la generación de código y manteniendo las modificaciones al mínimo.

Con el apoyo de Copilot, desarrollé múltiples scripts Bash que automatizan tareas clave y permiten generar todas las imágenes del sitio de manera ágil y creativa.

La primera versión me demandó alrededor de 12-15 horas de trabajo, y representa el inicio de una nueva etapa para este clásico sitio. Es una edición única que probablemente no reciba actualizaciones, pensada para que disfrutes la experiencia tal como está.

Espero que disfruten la experiencia y se diviertan navegando por él.
